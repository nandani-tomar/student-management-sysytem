# student-management-sysytem
Student Management System is a Python-based project used to manage student records efficiently. It allows users to add, view, search, update, and delete student information. The project demonstrates basic Python concepts such as functions, lists, dictionaries, loops, and conditional statements.Student Management System
About the Project
Student Management System is a simple Python project made for managing basic student information.﻿
In this project, we can add student details and view the information whenever required. The program is made using basic Python concepts that we learned in our course.﻿
I created this project to understand how Python can be used to make a small management system for a real-life situation.
Purpose of the Project
The main purpose of this project is to make student information easy to manage.﻿
Instead of entering and checking student details again and again, this program provides different options to manage the records in a simple way.

✨ What This Project Can Do
The program provides options to:
Add a new student
View student details
Search for a student
Update student information
Delete a student record
View all available student records
Exit the program

⚙️ How the Program Works
When we run the program, a simple menu is displayed.﻿
The user can select an option from the menu according to what they want to do.﻿
For example, if we select Add Student, the program asks for student details such as name, roll number, course, age, and marks.﻿
After entering the details, the student record is stored and can be viewed later.
